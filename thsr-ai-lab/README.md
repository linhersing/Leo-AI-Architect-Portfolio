# 高鐵 AI 動態研究展示｜V0.2

明亮、手機優先的五頁式研究概念網站。研究構想提供者：義守大學資訊管理研究所朱峻廷博士；網頁協助製作：凌鶴昇。

> **公開展示提醒**：這是獨立的教育與研究概念原型，非台灣高鐵官方網站；互動使用合成需求與容量指數，非真實營運資料、實測改善或安全認證。

## 網址與程式

- 預期 GitHub Pages： https://linhersing.github.io/Leo-AI-Architect-Portfolio/thsr-ai-lab/
- GitHub 目錄： https://github.com/linhersing/Leo-AI-Architect-Portfolio/tree/main/thsr-ai-lab

## 頁面導覽

| 網頁 | 重點 |
|---|---|
| index.html | 明亮簡潔的首頁，動態火車及三個主要入口 |
| simulation.html | 平日／假日／連假切換、車站人流、運能圖表、進階參數 |
| results.html | 三組研究情境假設和 100,000 次蒙地卡羅敏感度示範 |
| framework.html | PA、VA、AI4D、GEN、四維情境、公式、驗證與安全限制 |
| papers.html | 兩份研究稿的比較、研究成熟度、公開邊界與後續待確認事項 |

視覺樣式在 site.css；互動計算在 simulation.js。無第三方前端套件、後端或付費 API。

## 如何體驗

1. 打開首頁，點「開始互動體驗」。
2. 選「平日」「假日」或「連假」。
3. 觀察火車動畫、人潮示意、尖峰需求／運能比、排隊累積指數和曲線。
4. 想深入再開「進階調整」，拖動需求與運能倍率。
5. 點導覽列進入研究成果、模型架構、研究文件，避免把大量內容塞在首頁。

## 示範模型

- 曲線由為教育展示自行設定的 06:00–23:00 每小時需求／運能指數構成。
- 排隊示意：Q(t+1)=max(0, Q(t)+D(t)−C(t))。
- 尖峰需供比：max_t D(t)/C(t)。
- 高負載時段：D(t)/C(t)≥90% 的時段數。
- **這不是**朱老師論文裡 100,000 次蒙地卡羅模擬的原始碼；也不代表已完成高鐵數位雙生。
- **文件數值**（1,200→350 人、42→12 分鐘、160→75 秒及蒙地卡羅示範比例）全部在「研究成果」頁，並明確標示為「情境假設／示範」，不得宣稱真實改善。
