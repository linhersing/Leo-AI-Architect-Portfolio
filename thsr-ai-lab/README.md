## 使用方式

1. 開啟 `index.html`，或使用上方網站入口。
2. 在「模擬控制台」選擇平日、一般假日或極端連假。
3. 調整旅客需求倍率、可用服務運能倍率。
4. 觀察需求／運能趨勢、尖峰供需比、最高累積排隊指數、簡化等待時間估計，以及高負載時段數。
5. 列車動畫可播放或暫停；它只是視覺示意，**不是**即時列車定位或時刻表。

## 模型與數值來源

- 構想參照朱峻廷博士提供的兩份 2026 年 11 月研究／規劃稿；未在這個公開 repository 上傳研究原始 Word。
- 互動數值使用為教育展示**自行設定的合成需求曲線與運能指數**，不是從高鐵官方資料取得或訓練。
- 模型每個小時的累積排隊指數：`Q[t+1] = max(0, Q[t] + demand[t] - capacity[t])`。
- 峰值供需比：各時段 `demand[t]/capacity[t]` 的最大值。
- 候車時間估計：每時段 `Q[t]/capacity[t]×60` 的平均值，只是簡化教學計算，未考慮客流實際分布或服務流程。
- 高負載時段：需求／運能達 90% 以上的時段數。
- 操作倍率會重新運算；**不能據此推論**增加班次、改變停站或行車安全的真實效果。

## 範圍與邊界

**已實作**：純瀏覽器單頁展示、情境切換、參數控制、動態 SVG 圖表、模擬統計、路線上的動態列車圖示、研究架構與使用聲明、手機排版。

**未實作**：台灣高鐵公開或內部 API 串接、真實數位雙生、營運決策系統、可重現的 100,000 次蒙地卡羅模擬、授權資料匯入、註冊／管理後台、官方研究驗收。
